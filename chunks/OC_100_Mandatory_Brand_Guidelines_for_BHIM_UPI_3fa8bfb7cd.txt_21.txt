What is UPI ID
UPI ID: user@upihandle
Here, ‘user’ is prefix and ‘upihandle’ is suffix
UPI ID display style:
UPI ID of the user should always be displayed at the home page 
below the partner apps logo.
Font typeface: Font to be used is of the partner’s respective font 
typeface.
Font size: UPI ID should be clearly visible and equal to the size of 
app logo in height.
Font colour: On a white/light coloured background, font colour can 
be of the respective partner brand colour. And on a dark 
background, font colour should be white.
And should mention the word UPI ID before the UPI ID as 
represented below.
